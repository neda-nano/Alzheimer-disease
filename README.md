# Alzheimer Disease Prediction

This project focuses on analyzing data and predicting Alzheimer’s disease using machine learning algorithms in Python.

## Project Description

The dataset contains features such as age, gender, diabetes, and more. The goal is to predict the Alzheimer’s disease status based on these features by performing data preprocessing and applying machine learning models.

## Data

- Contains 5 rows and 34 columns (35 features)  
- Features include demographic and medical information  
- The target variable is the disease diagnosis

## Project Steps

1. Data preprocessing (cleaning, normalization, and preparation)  
2. Splitting the data into training and testing sets  
3. Applying PCA (Principal Component Analysis) for dimensionality reduction  
4. Training machine learning models (e.g., Random Forest)  
5. Plotting feature importance to understand key predictors  
6. Evaluating the model using accuracy and other metrics
